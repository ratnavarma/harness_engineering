Harness Engineering Workshop · 7–9 AM IST

Build the agent
you can explain.

Assembler is a minimal Python harness built in public over five mornings: no agent SDK, no hidden magic, and no layer you cannot inspect.

By Friday, this runs on your machine — and you wrote every line.

A terminal coding agent that reads and edits real files, asks before dangerous actions, compacts its context, checkpoints its work, resumes after a crash, and dispatches sub-agents.

Day 2 complete

Provider adapter, agent loop, six confined local tools, and an approval policy are implemented in Assembler/.

The curriculum

01

Day 1 · 7–9 AM IST Built

The Anatomy of a Harness

  • Why “just call the API” fails: transactional inference vs. a real agent
  • Dissect Claude Code, pi, and Hermes: what every layer does
  • Prompt vs. context vs. harness engineering; messages, turns, stop conditions, and streaming

You build — a bare harness: model client, message array, and a hand-rolled loop that runs until the model stops asking for work.

02

Day 2 · 7–9 AM IST Built

Tools & the Execution Environment

  • Tool schemas as contracts: read, write, edit, bash, and search
  • Streaming tool calls and partial results into a terminal UI
  • Permission gates, approval modes, sandboxing, and blast radius

You build — real file and shell tools wired into your loop, able to edit code safely on your machine.

03

Day 3 · 7–9 AM IST

Context Engineering Inside the Harness

  • Context budgets: what belongs in every turn and what gets evicted
  • Compaction and summarization for long-running sessions
  • Session state, persistent memory files, and system prompts as infrastructure

You build — compaction plus persistent memory, so the harness survives a 200-turn session.

04

Day 4 · 7–9 AM IST

Durability, Recovery & Orchestration

  • Checkpoint every model turn and tool call; replay after restart
  • Retries, failure classification, resumable sessions, and self-healing loops
  • Sub-agents, handoffs, supervision, plans, approvals, and escalation

You build — checkpointed execution and a sub-agent dispatcher with an approval gate.

05

Day 5 · 7–9 AM IST

Production Harnesses & Capstone

  • pi internals: extensions, models.json, and minimal surface area
  • Hermes and Claude Code: skills, hooks, MCP, and sub-agent types
  • Harness evaluation: how you know yours actually works

Capstone — assemble and demo your pi-style harness: loop, tools, context engine, recovery, and orchestration.
