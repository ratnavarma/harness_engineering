Day 1 · the agent loop

A neutral model harness

Implemented Assembler/provider.py and Assembler/loop.py, plus the day1_dice.py demo.

  • Gemini client converts neutral messages to provider wire format and preserves thought signatures across tool turns.
  • Retry backoff contains transient API failures; response parsing returns text, tool calls, and usage.
  • The loop emits events, executes calls in order, catches tool failures, and has a final turn-limit wrap-up.

Day 2 · tools & guardrails

A confined coding environment

Implemented Assembler/tools.py, Assembler/security.py, and the day2_build.py demo.

  • Six real tools: read, write, unique edit, shell, file listing, and regex search—each file path is confined to the working directory.
  • Policy modes support read-only, approval-gated safe mode, and yolo mode; dangerous shell commands remain blocked in every mode.
  • Verified with Gemini: an iterative fib.py was created and run in a temporary directory, producing 832040.
  • Safety checks: home-directory deletion returns a blocked tool result, and an attempted ../../etc/passwd read raises an escapes the working directory permission error rather than crashing the loop.
